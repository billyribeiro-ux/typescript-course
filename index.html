How to use this course

Every lesson is a self-contained page with live, editable code editors (powered by a locally-bundled Monaco — the same editor as VS Code). It works fully offline: just open the files. Read top-to-bottom, copy the code, run the projects, and use the Next / Previous buttons to move through the curriculum. For live type-checking inside the editors, serve the folder over localhost (see the README) — opening via file:// still gives you full syntax highlighting and copy/paste.
