Advanced TanStack Query

🧩 Ecosystem ⏱️ ~32 min ✏️ Mutations & more

Reading data is half the story; real apps also write it. useMutation handles creates/updates/deletes with pending and error states, and pairs with cache invalidation and optimistic updates for instant-feeling UIs. We'll also cover infinite queries and prefetching — the patterns that make data-heavy apps feel fast.

1. Mutations & cache invalidation

useMutation.tsxtsx 
import { useMutation, useQueryClient } from "@tanstack/react-query";

function AddTodo() {
  const queryClient = useQueryClient();
  const mutation = useMutation({
    mutationFn: (title: string) =>
      fetch("/api/todos", { method: "POST", body: JSON.stringify({ title }) }),
    onSuccess: () => {
      // Mark the todos list stale → Query refetches it automatically:
      queryClient.invalidateQueries({ queryKey: ["todos"] });
    },
  });

  return (
    <button
      disabled={mutation.isPending}
      onClick={() => mutation.mutate("New todo")}
    >
      {mutation.isPending ? "Adding…" : "Add todo"}
    </button>
  );
}
The read-write cycle: useMutation performs the write and gives you isPending/isError. On success, you invalidateQueries the affected keys, and TanStack Query refetches them so the UI reflects the new server state. This "invalidate after mutate" loop keeps your cache and server in sync with almost no code.

2. Optimistic updates

optimistic.tsxtsx 
const mutation = useMutation({
  mutationFn: toggleTodo,
  // Update the cache IMMEDIATELY, before the server responds:
  onMutate: async (id) => {
    await queryClient.cancelQueries({ queryKey: ["todos"] });
    const previous = queryClient.getQueryData<Todo[]>(["todos"]);
    queryClient.setQueryData<Todo[]>(["todos"], (old) =>
      old?.map((t) => (t.id === id ? { ...t, done: !t.done } : t)) ?? []);
    return { previous }; // context for rollback
  },
  onError: (_err, _id, context) => {
    queryClient.setQueryData(["todos"], context?.previous); // roll back
  },
  onSettled: () => queryClient.invalidateQueries({ queryKey: ["todos"] }),
});
Optimistic updates make the UI feel instant. onMutate writes the expected result to the cache immediately (snapshotting the old value); onError rolls back if the request fails; onSettled refetches to reconcile with the truth. This is the same idea as React 19's useOptimistic (04-12), at the data-cache layer.

3. Infinite queries & prefetching

infinite-prefetch.tsxtsx 
import { useInfiniteQuery } from "@tanstack/react-query";

const { data, fetchNextPage, hasNextPage } = useInfiniteQuery({
  queryKey: ["feed"],
  queryFn: ({ pageParam }) => fetchFeed(pageParam),
  initialPageParam: 0,
  getNextPageParam: (lastPage) => lastPage.nextCursor, // null = no more
});
// "Load more" / infinite scroll, with all pages cached together.

// Prefetch on hover so the next page is instant when clicked:
<Link onMouseEnter={() =>
  queryClient.prefetchQuery({ queryKey: ["product", id], queryFn: () => fetchProduct(id) })
} to={`/products/${id}`}>…</Link>;
Two power features: useInfiniteQuery handles paginated/infinite-scroll lists with cursor-based loading and caches all pages. prefetchQuery warms the cache before the user navigates (e.g. on hover), so the destination renders instantly. These are the patterns behind snappy feeds and product browsers.
⚡
Pro-tip · Wrap queries in custom hooks

Don't scatter useQuery calls everywhere. Wrap each in a custom hook (useProducts(), useProduct(id)) that owns the query key and fetcher. This centralises your data layer, keeps keys consistent, and makes components clean — the same encapsulation principle as P03's useWeather.

🎓 Key takeaways

  • useMutation handles writes with pending/error states; invalidate affected query keys on success.
  • Optimistic updates (onMutate/onError/onSettled) make writes feel instant with safe rollback.
  • useInfiniteQuery powers paginated/infinite lists; prefetchQuery warms the cache ahead of navigation.
  • Wrap queries/mutations in custom hooks to centralise your data layer.
  • Together with 06-03, this is the complete, robust data layer for any React app.
