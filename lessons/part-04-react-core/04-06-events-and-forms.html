Handling Events & Forms

⚛️ React + TS ⏱️ ~30 min ⌨️ User input

Interactivity means responding to user actions — clicks, typing, submitting. React handles events with typed handler props, and forms with the controlled component pattern, where React state is the single source of truth for input values. Getting forms right (and typed) is a daily React task, and the foundation for React Hook Form in Part 6.

1. Event handlers

events.tsxtsx 
function Buttons() {
  // Inline handler:
  return (
    <div>
      <button onClick={() => console.log("clicked")}>Inline</button>

      {/* Named handler — preferred for anything non-trivial: */}
      <button onClick={handleSave}>Save</button>

      {/* Pass arguments by wrapping in an arrow: */}
      <button onClick={() => handleDelete(42)}>Delete</button>
    </div>
  );

  function handleSave() { console.log("saved"); }
  function handleDelete(id: number) { console.log("delete", id); }
}
Pass the function, don't call it. onClick={handleSave} passes the function (React calls it on click). onClick={handleSave()} would call it immediately during render — a common beginner bug. To pass arguments, wrap in an arrow: onClick={() => handleDelete(42)}.

2. Typing events

typed-events.tsxtsx 
import type { ChangeEvent, FormEvent, MouseEvent } from "react";

function handleChange(e: ChangeEvent<HTMLInputElement>) {
  console.log(e.target.value);   // value is typed as string
}

function handleSubmit(e: FormEvent<HTMLFormElement>) {
  e.preventDefault();            // stop the browser's full-page reload
  // ...read form state and submit...
}

function handleClick(e: MouseEvent<HTMLButtonElement>) {
  console.log(e.currentTarget.disabled);
}

// Often you don't need to annotate — inline handlers infer the event type:
<input onChange={(e) => console.log(e.target.value)} />; // e is inferred!
React's event types are generic over the element: ChangeEvent<HTMLInputElement>, FormEvent<HTMLFormElement>. You only need to annotate when defining a handler separately — inline handlers infer the event type automatically. e.preventDefault() on submit stops the default page reload, which is essential for SPAs.

3. Controlled form inputs

ControlledForm.tsxtsx 
import { useState } from "react";

function SignupForm() {
  const [email, setEmail] = useState("");
  const [agreed, setAgreed] = useState(false);

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    console.log({ email, agreed });   // React state IS the form data
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="email"
        value={email}                              // value comes FROM state
        onChange={(e) => setEmail(e.target.value)}  // changes go TO state
        placeholder="you@example.com"
      />
      <label>
        <input type="checkbox" checked={agreed}
               onChange={(e) => setAgreed(e.target.checked)} />
        I agree
      </label>
      <button type="submit" disabled={!email || !agreed}>Sign up</button>
    </form>
  );
}
The controlled-component pattern is the heart of React forms: the input's value is driven by state, and onChange writes every keystroke back to state. State is the single source of truth — the input can't get out of sync. This makes validation, disabling the submit button, and resetting trivial (note disabled={!email || !agreed}).
⚡
Pro-tip · One handler for many fields

For larger forms, hold all fields in one state object and use a single change handler keyed by the input's name: setForm(f => ({ ...f, [e.target.name]: e.target.value })). But beyond a few fields, reach for React Hook Form + Zod (Part 6) — it handles validation, performance, and errors for you. Here you're learning the fundamentals it's built on.

🎓 Key takeaways

  • Pass handlers, don't call them: onClick={fn}, and wrap in an arrow to pass args.
  • React event types are generic: ChangeEvent<HTMLInputElement>, FormEvent<HTMLFormElement>; inline handlers infer them.
  • e.preventDefault() stops the default form reload in SPAs.
  • Controlled components: value from state + onChange to state = single source of truth.
  • For real forms at scale, graduate to React Hook Form + Zod (Part 6).
