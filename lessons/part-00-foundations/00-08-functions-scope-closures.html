Functions, Scope & Closures

🎯 Beginner → Core ⏱️ ~30 min 🧱 The building block

Functions are the most important concept in programming. A function is a reusable, named block of logic that takes inputs and produces an output. Master functions — including arrow functions, scope, and closures — and you've mastered the unit that every program, and all of React, is built from.

1. Declaring and calling functions

functions.jsjavascript 
// A function declaration: name, parameters, body.
function add(a, b) {
  return a + b;     // 'return' sends a value back to the caller
}

// "Call" (run) it with arguments:
const sum = add(3, 4);   // sum is 7
console.log(sum);

// Functions can do anything and return anything:
function greet(name) {
  return `Hello, ${name}!`;
}
console.log(greet("Lin")); // Hello, Lin!
Vocabulary: a and b are parameters (the named inputs); 3 and 4 are arguments (the actual values). return hands a result back. A function without return gives back undefined.

2. Arrow functions (the modern style)

Arrow functions are a shorter syntax you'll see everywhere, especially in React. They're ideal for small functions and for passing logic to other functions.

arrows.jsjavascript 
// These three are equivalent:
function squareA(n) { return n * n; }
const squareB = (n) => { return n * n; };
const squareC = (n) => n * n;   // implicit return when there's no braces

console.log(squareC(5)); // 25

// Multiple params need parentheses; zero params use ()
const multiply = (a, b) => a * b;
const sayHi = () => "hi";

// Default parameter values:
const greet = (name = "friend") => `Hello, ${name}`;
console.log(greet());        // Hello, friend
console.log(greet("Sam"));   // Hello, Sam
Key forms: (n) => n * n implicitly returns its expression. (n) => { ... return x } needs an explicit return. Default values (name = "friend") make parameters optional.

3. Functions are values

Here's the idea that unlocks React: functions are just values. You can store them in variables, pass them into other functions, and return them. A function passed to another function is called a callback.

callbacks.jsjavascript 
// A function that takes another function as input:
function repeat(times, action) {
  for (let i = 0; i < times; i++) {
    action(i);   // call the passed-in function
  }
}

repeat(3, (i) => console.log(`Step ${i}`));
// Step 0 / Step 1 / Step 2

// This pattern powers array methods, event handlers, and React.
const numbers = [1, 2, 3];
numbers.forEach((n) => console.log(n * 10)); // 10, 20, 30
Why it matters: when you write a React button as <button onClick={handleClick}>, you're passing a function as a value — exactly this concept. Callbacks are the connective tissue of JavaScript.

4. Scope: where variables live

Scope is the region where a variable is visible. Variables declared inside a function (or any { } block with const/let) are local — invisible outside. Inner code can see outer variables, but not vice versa.

scope.jsjavascript 
const appName = "MyApp";   // outer (module) scope

function showName() {
  const greeting = "Welcome";          // local to showName
  console.log(`${greeting} to ${appName}`); // can see both
}

showName();
// console.log(greeting); // ❌ ReferenceError: greeting is not defined

// Each call gets its own fresh local variables.
The rule: look outward, never inward. showName can read the outer appName, but the outside world can't read its private greeting. This isolation keeps programs from becoming tangled messes.

5. Closures (the famous one)

A closure is what you get when a function "remembers" the variables from where it was created, even after that outer function has finished. It sounds abstract; the example makes it click — and it's the basis of how React's useState remembers your data.

closures.jsjavascript 
function makeCounter() {
  let count = 0;                 // private state
  return () => {                 // this inner function "closes over" count
    count += 1;
    return count;
  };
}

const next = makeCounter();
console.log(next()); // 1
console.log(next()); // 2
console.log(next()); // 3  — it remembers count between calls!

// A separate counter has its own independent memory:
const other = makeCounter();
console.log(other()); // 1
What's happening: makeCounter returns a function that keeps access to its own private count. Each counter has independent memory. This "function + remembered variables" bundle is a closure — one of JavaScript's most powerful ideas, and the secret behind React Hooks.

🎓 Key takeaways

  • Functions take parameters and return a result; calling supplies arguments.
  • Arrow functions ((x) => x * 2) are the modern, concise style used throughout React.
  • Functions are values — pass them as callbacks to other functions.
  • Scope: inner code sees outer variables, not the reverse; locals stay private.
  • A closure lets a function remember the variables it was created with — the foundation of React Hooks.
