The Command Line From Zero

🎯 Beginner ⏱️ ~20 min ⌨️ Terminal fluency

The command line (a.k.a. the terminal or shell) feels intimidating at first and then becomes the single fastest way to control your computer. Every professional engineer is fluent in it. In this lesson you'll learn the handful of commands that cover 95% of daily work — navigating folders, creating files, and running programs — and the mental model that ties them together.

1. What the terminal actually is

The terminal is a text-based way to talk to your computer. Instead of clicking icons, you type a command and press Enter; a program called a shell reads it, runs it, and prints the result. The most common shells are zsh and bash (macOS/Linux) and PowerShell (Windows). The commands below are nearly identical across all of them.

🧭
Concept · The "current directory"

At every moment, your terminal is "standing inside" one folder — the current working directory. Most commands act relative to where you're standing. Knowing where you are is the whole game.

2. The core commands

CommandDoes
pwdPrint working directory — "where am I?"
lsList the files/folders here. (ls -la shows hidden + details.)
cd folderChange directory — walk into a folder.
cd ..Go up one level to the parent folder.
mkdir nameMake a new directory (folder).
touch file.txtCreate an empty file (macOS/Linux).
cat filePrint a file's contents.
rm fileRemove a file. Careful — no recycle bin!
clearClear the screen.

3. A guided walk-through

Follow along in your own terminal. Read the comments to understand each step:

terminal session
pwd
/Users/you
mkdir practice           # make a folder
cd practice              # step into it
touch notes.txt app.js   # create two files
ls
app.js   notes.txt
cd ..                    # go back up
ls practice             # peek inside without entering
app.js   notes.txt
⚡
Pro-tip · The three biggest time-savers
  • Tab auto-completes file and folder names. Type cd pr then Tab.
  • ↑ / ↓ arrows scroll through your previous commands.
  • cd with no argument jumps straight to your home folder.

4. Paths: absolute vs relative

A path is an address for a file. Relative paths start from where you're standing (./app.js, ../images/logo.png). Absolute paths start from the root of the disk (/Users/you/practice/app.js or C:\Users\you\practice\app.js). Two symbols you'll use constantly:

  • . means "the current folder".
  • .. means "the parent folder".
  • ~ means "my home folder".

5. Running your tools from here

Everything you'll do in this course is driven from the terminal: running programs with node, installing packages with pnpm install, starting dev servers with pnpm dev, and committing code with git. The terminal is the control room. Get comfortable here and the rest of the course flows.

⚠️
Gotcha · rm is forever

rm and especially rm -rf folder delete permanently — there is no trash bin. Read the path twice before pressing Enter. This is a rite of passage; respect it early.

📝
Exercise · Build a folder tree blind

Using only the terminal, create this structure: a folder course containing a folder part0, which contains a file lesson3.txt. Then cd into part0, run pwd to confirm where you are, and ls to confirm the file exists. No mouse allowed.

🎓 Key takeaways

  • The terminal is a text interface to your computer; you're always "standing in" one folder.
  • Master pwd, ls, cd, mkdir, touch, cat, rm.
  • . = here, .. = up, ~ = home. Tab completes; ↑ recalls.
  • All your tools — node, pnpm, git — are launched from here.
  • rm is permanent. Always check the path first.
