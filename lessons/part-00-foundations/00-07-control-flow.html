Operators, Conditionals & Control Flow

🎯 Beginner ⏱️ ~26 min 🔀 Logic & decisions

Programs make decisions and repeat work. Control flow is how you direct that: running different code depending on conditions, and looping over data. Combined with operators — the verbs of the language — this is where your code starts to feel genuinely alive.

1. Operators you'll use daily

CategoryOperators
Arithmetic+ - * / % (% = remainder), ** (power)
Comparison=== !== (equal / not), < > <= >=
Logical&& (and), || (or), ! (not)
Assignment= += -= *=
⚠️
Gotcha · Always use === , never ==

JavaScript has a loose == that silently converts types (0 == "" is true!). It's a notorious bug source. Always use the strict === and !==, which compare without surprises. Professionals never use ==.

2. if / else if / else

conditions.jsjavascript 
const score = 78;

if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else if (score >= 70) {
  console.log("C");   // this runs
} else {
  console.log("Keep practising");
}

// Combine conditions with && and ||
const age = 20;
const hasTicket = true;
if (age >= 18 && hasTicket) {
  console.log("Welcome in!");
}
What's happening: JavaScript checks each condition top-to-bottom and runs the first block whose condition is true. && requires both sides true; || requires either.

3. Truthy & falsy

In a condition, non-boolean values are coerced to true/false. The falsy values are few — memorise them: false, 0, "" (empty string), null, undefined, NaN. Everything else is truthy.

truthy.jsjavascript 
const username = "";

if (username) {
  console.log("Hi, " + username);
} else {
  console.log("Please enter a name"); // runs: "" is falsy
}

// Modern, super-common patterns:
const input = null;
const name = input ?? "Guest";   // ?? = "use right side if left is null/undefined"
console.log(name);               // "Guest"

const config = { theme: "dark" };
const theme = config.theme || "light"; // || = "use right side if left is falsy"
console.log(theme);              // "dark"
2020+ operators: ?? (nullish coalescing) only falls back on null/undefined, while || falls back on any falsy value. Use ?? when 0 or "" are valid values you want to keep.

4. Loops: repeating work

The modern workhorse is for...of, which walks through every item in a list. You'll also meet the classic counting for and the while loop.

loops.jsjavascript 
const fruits = ["apple", "banana", "cherry"];

// Modern: for...of (read as "for each fruit of fruits")
for (const fruit of fruits) {
  console.log(fruit.toUpperCase());
}

// Classic counting loop (when you need the index)
for (let i = 0; i < fruits.length; i++) {
  console.log(`${i + 1}. ${fruits[i]}`);
}

// while: repeat until a condition becomes false
let countdown = 3;
while (countdown > 0) {
  console.log(countdown);
  countdown -= 1;   // shorthand for countdown = countdown - 1
}
What's happening: for...of hands you each item directly — cleanest for most cases. The counting for gives you an index i. while keeps going until its condition is false (don't forget to change the condition, or it loops forever!).

5. switch & the ternary

switch-ternary.jsjavascript 
const day = "sat";

switch (day) {
  case "sat":
  case "sun":
    console.log("Weekend!");
    break;            // stop here — don't fall through
  default:
    console.log("Weekday");
}

// Ternary: a one-line if/else that produces a value
const age = 17;
const status = age >= 18 ? "adult" : "minor";
console.log(status); // "minor"
The ternary condition ? a : b is everywhere in React for conditional rendering, so get comfortable with it. switch is handy when comparing one value against many fixed options — remember break.

🎓 Key takeaways

  • Use ===/!== — never the loose ==.
  • if/else if/else branches; the ternary ?: is a one-line value-producing version.
  • Falsy values: false 0 "" null undefined NaN. Everything else is truthy.
  • ?? falls back only on null/undefined; || on any falsy value.
  • Prefer for...of to loop items; use counting for when you need the index.
